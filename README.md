# Statistical Methods for Doctoral Students (Applied Software Engineering Track)

Welcome to the course repository for **Statistical Methods**. 

Unlike traditional lecture-based courses, this course focuses on the practical application of statistical methods and computational software engineering. Students will select a peer-reviewed methodology paper relevant to their PhD dissertation and re-implement its statistical methods/algorithms into a clean, reusable, and open-source software package or toolchain (in **R**, **Python**, or **C++**).

---

## Course Objectives

By the end of this course, you will:
1. Translate advanced theoretical/statistical methodology into production-ready code.
2. Develop an open-source software package or executable tool (R Package, Python Library/CLI, or C++ Module).
3. Master modern collaborative tools: Git, GitHub Workflows, Pull Requests, Continuous Integration (CI/CD), and Peer Review.
4. Enhance the reproducibility and technical quality of your PhD research.

---

## Accepted Programming Languages
Students may choose any of the following languages for their final implementation:
* **R** (e.g., standard package, `Rcpp`, `S3`/`R6` OOP)
* **Python** (e.g., installable library, CLI tool using `numpy`/`scipy`/`polars`)
* **C++** (standalone library or high-performance binding for R/Python)

---

## Course Workflow & Key Milestones

| Phase | Task | Deliverable |
| :--- | :--- | :--- |
| **Phase 1** | Paper Selection & Approval | Submit a Pull Request to `proposals/` |
| **Phase 2** | Implementation & "Mid-Term" Pipeline | Functional draft in your repository |
| **Phase 3** | Peer Review (Code Freeze & Audit) | Conduct GitHub Peer Review on assigned repo |
| **Phase 4** | Final Rebuttal & Release | Address review issues & submit v1.0 release |

---

## Grading & Assessment

| Component | Weight | Objective |
| :--- | :--- | :--- |
| **GitHub Peer Reviews** | **10%** | Active participation in reviewing peers' code via PRs and Issues. |
| **"Mid-Term" Pipeline** | **30%** | Testing repository setup, unit tests, build pipeline (CI/CD), and core logic. |
| **Final Project Package** | **60%** | Re-implemented methodology paper, full documentation, test coverage, and benchmark/example dataset. |
